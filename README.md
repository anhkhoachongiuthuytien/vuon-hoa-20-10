# 🌸 Cả một vườn thương... - Chúc Mừng Ngày Phụ Nữ Việt Nam 20/10

Một món quà công nghệ đong đầy tình cảm dành tặng cho những người phụ nữ tuyệt vời nhân ngày 20/10.

Trang web mô phỏng khu vườn hoa giấy cuộn nghệ thuật (Paper Quilled Flowers) nở rộ trong gió, với hiệu ứng lá bay lãng mạn và thiệp chúc mừng ý nghĩa.

![Demo](anh_minh_hoa/image%20copy.png)

## ✨ Điểm nổi bật & Tính năng

1. **Hiệu ứng nở hoa 2 giai đoạn:**
   - **Giai đoạn 1:** Khởi đầu với một đóa hồng nhỏ nhẹ nhàng vươn lên từ mặt đất, kèm thông điệp *"Từ một bông hoa, cả khu vườn đang thức giấc..."*.
   - **Giai đoạn 2:** Cả một khu vườn gồm hơn 40 đóa hồng giấy và nụ hoa đa sắc màu (hồng, cam đào, vàng nắng, xanh bạc hà, xanh thiên thanh, tím lavender, san hô) đồng loạt đâm chồi, nở rộ và lung lay nhịp nhàng trong gió.

2. **Thiệp chúc mừng trang nhã (Greeting Card Modal):**
   - Thiết kế chuẩn phong cách thiệp vintage / paper craft với khung bo viền xanh sage tinh tế.
   - Lời chúc ý nghĩa ngày 20/10 dành cho phái đẹp.
   - Nút **"Ngắm vườn hoa"** cho phép thu nhỏ thiệp để thỏa sức chiêm ngưỡng cả khu vườn.
   - Nút **"💌 Xem thiệp"** ở góc phải giúp mở lại thiệp bất cứ lúc nào.

3. **Gió thổi & Lá rơi tự nhiên:**
   - Các bông hoa lung lay hữu cơ theo làn gió mùa thu với chu kỳ và độ trễ ngẫu nhiên.
   - Canvas hiệu ứng những chiếc lá nhỏ và cánh hoa 3D chao lượn, rơi nhẹ nhàng trên nền trời xanh mây trắng.

4. **Âm nhạc lãng mạn & Tương tác:**
   - Tích hợp giai điệu Piano Acoustic ngọt ngào (sử dụng Web Audio API không phụ thuộc file ngoài, phát ngay lập tức trên mọi thiết bị).
   - Chạm/click bất kỳ vị trí nào trên màn hình để tạo hiệu ứng bùng nổ cánh hoa và ánh sao lấp lánh.
   - Hỗ trợ cá nhân hóa tên người nhận qua URL query parameter (ví dụ: `?to=Thủy Tiên` hoặc `?name=Mẹ`).

## 💻 Hướng dẫn chạy cục bộ (Local)

Chỉ cần mở file `index.html` trực tiếp bằng trình duyệt bất kỳ (Chrome, Safari, Edge, Firefox), hoặc chạy local server:

```bash
# Sử dụng Python
python -m http.server 8000

# Mở trình duyệt tại http://localhost:8000
```
